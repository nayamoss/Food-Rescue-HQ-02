---
name: Mobile usability
description: Phone usability is a standing requirement for Food Rescue HQ.
---

Preserve phone usability when adding or changing dashboard features.

**Why:** The user explicitly said “i need this to be mobile optimisted” about the running Food Rescue HQ app.

**How to apply:** Keep controls touch-friendly, text readable, and tables within narrow viewports. Do not assume desktop-only use or interpret this as a request for a separate native app.
